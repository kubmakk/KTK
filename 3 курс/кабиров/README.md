# Практические работы 2 и 3 на C# Windows Forms

В папке находится одно решение Visual Studio с двумя независимыми проектами:

- `Практическая2_СписокЗадач` — добавление, удаление, сортировка и сохранение заметок, а также передача заметок на вторую форму с флажками;
- `Практическая3_КаталогКниг` — авторизация и каталог книг с разными правами гостя, пользователя, модератора и администратора.

## Как открыть

1. Перенесите всю папку `Практические_CSharp` на компьютер с Windows.
2. Установите Visual Studio 2022 с компонентом **Разработка классических приложений .NET**.
3. Откройте файл `Практические_CSharp.sln`.
4. В обозревателе решений нажмите правой кнопкой по нужному проекту и выберите **Назначить запускаемым проектом**.
5. Запустите проект клавишей `F5` или сочетанием `Ctrl+F5`.

Оба проекта используют .NET 8 и не требуют сторонних библиотек или базы данных.

## Где читать объяснения

- `Пояснение_Практическая_2.md` — подробный разбор практической 2;
- `Пояснение_Практическая_3.md` — подробный разбор практической 3.

## Данные для входа в практической 3

| Роль | Логин | Пароль | Доступные действия |
|---|---|---|---|
| Гость | отдельная кнопка | не нужен | просмотр каталога |
| Пользователь | `user` | `user123` | просмотр каталога |
| Модератор | `moderator` | `mod123` | просмотр и сортировка |
| Администратор | `admin` | `admin123` | просмотр, сортировка, добавление и удаление |

## Что показать преподавателю

Для практической 2:

1. Добавьте несколько заметок кнопкой и клавишей `Enter`.
2. Удалите выбранную заметку кнопкой, затем другую клавишей `Delete`.
3. Отсортируйте список.
4. Сохраните его в `.txt`.
5. Откройте вторую форму и поставьте несколько галочек.

Для практической 3:

1. Покажите сообщение об ошибке при неверном пароле.
2. Войдите гостем: виден только список и кнопка выхода.
3. Войдите модератором: появляется сортировка.
4. Войдите администратором: появляются поле ввода, добавление и удаление.
5. Обратите внимание, что недоступные элементы скрыты, а не заблокированы.
